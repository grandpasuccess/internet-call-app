# Mobile Frontend - Internet Call App

## Quick Start

```bash
cd frontend/mobile
pnpm install
pnpm start
```

## Scripts

- `pnpm start` - Start Expo development server
- `pnpm android` - Start on Android emulator
- `pnpm ios` - Start on iOS Simulator
- `pnpm web` - Start web version
- `pnpm test` - Run tests

## Requirements

- Node.js >= 16.0.0
- Expo CLI (`pnpm install -g expo-cli`)
- For iOS: macOS with Xcode
- For Android: Android Studio with emulator or device

## Environment

Copy `.env.example` to `.env` and configure for your environment.

## Project Structure

- `src/screens/` - Screen components
- `src/components/` - Reusable UI components
- `src/services/` - API and socket services
- `src/navigation/` - React Navigation configuration
- `src/utils/` - Utility functions
